# xtc documentation

Documentation for xtc, the compiler for the Atari 8-bit range.

- `xtc.md`: the language manual (preprocessor, command-line options, memory models, language, support files).
- `xtc.bnf`: the grammar of the xtc source language.
- `xt-usage.md`: a summary of the xt memory model.
- `68k/sim68k.md`: `xst`, the Atari ST (68000/68030) simulator.
- `LICENSE`: the GNU General Public License, version 3.
