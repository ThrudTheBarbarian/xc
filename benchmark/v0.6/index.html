xc against Objective-C

The same programs in both languages, both with automatic reference counting, built at four optimisation levels.

Each figure is the fastest of the runs. Every program times its own measured region with clock_gettime(CLOCK_MONOTONIC), so process startup and data setup are outside the number. Both programs print a checksum and a run is rejected if they disagree.

The arm64 Objective-C column is Apple's runtime and Foundation; the x86-64 column is libobjc2 and gnustep-base. Comparing a ratio across the two platforms therefore also compares two different Objective-C implementations, which matters most for the benchmarks dominated by allocation and dispatch.
