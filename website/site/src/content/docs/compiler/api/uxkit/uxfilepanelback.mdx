---
title: UXFilePanelBack
description: "The dialog-face backdrop of the toolkit file panel: one fill, so the panel reads as a dialog on any window."
---

`UXFilePanelBack` is the backdrop of the
[`UXFilePanel`](/compiler/api/uxkit/uxfilepanel/). It paints a single
dialog-face fill behind the panel's controls, so the panel reads as a
dialog over any window. It implements one `drawRect` and nothing else.
