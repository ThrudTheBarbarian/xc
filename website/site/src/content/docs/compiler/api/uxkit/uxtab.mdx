---
title: UXTab
description: "One tab of a UXTabView: a label and the content view it shows."
---

`UXTab` is one tab of a [`UXTabView`](/compiler/api/uxkit/uxtabview/): a
`label` and the `content` view shown when it is selected. `addTab(label,
content)` makes them; `labelAt` / `contentAt` read them back.
