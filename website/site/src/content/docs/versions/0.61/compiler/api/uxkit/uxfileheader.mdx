`UXFileHeader` is the column-title strip of the
[`UXFilePanel`](/versions/0.61/compiler/api/uxkit/uxfilepanel/). It shows Name and Size,
marks the current sort column and shows its direction. A click sorts by
that column, and a second click flips between ascending and descending. The
panel owns the sort state; the header paints it and reports clicks.
